To update the metadata of the app we need to get a fresh data from Gdevelop and replace it with gdevelop-metadata.json

- Copy the code in extract-extension.js
- Open editor.gdevelop.com 
- Open the console (F12 or Ctrl + Shift + I)
- Paste the code inside and hit enter
- Wait for a while and the metadata is downloaded
- Copy it to the data directory
- Replace the gdevelop-metadata.json with the new file
