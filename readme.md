**GDWisp** is a tool for GDevelop that aids collaboration through a visual git interface and project management. Check out more about GDWisp at [our website](https://www.gdwisp.com) (with screenshots).

> Project management is a planned feature

**Current Features**
- **Git workflow:** commit, push, pull, sync and link, with live progress
- **Branch tools:** change, create, rename and delete, with autostash
- **Remote tools:** add and remove
- **Advanced tools:** revert, reset, and restore (stash pop)
- **History:** a Git graph with colored lanes and lazy loading
- **Project setup:** adding a project initializes Git and a .gitignore
- **Live updates:** project and Git file watchers
- **Projects Supported:** Properties, Global Variables
- **Scenes Supported:** Layers, Objects, Groups, Instances, Events, Properties
-  **Objects Supported:** Behavior, Effects
- **Events Supported:** Comments, Standard Events
- **Variables Supported:** Array, String, Number, Boolean
- **Resources Supported**

Check out our roadmap, philosophy and goals at [Roadmap - GDWisp](https://www.gdwisp.com/roadmap)

**Known Bugs**
- Missing some features (Alpha stage)
- Some features are slow on large projects (Events Rendering)
You can help us fix nasty bugs at [contribute](docs/contribute.md)

## How to Use
- Download the latest from Releases
- Requires Git (https://git-scm.com)
- Extract the zip
- Run gdwisp executable (App not signed so it may show SmartScreen on Windows)
- Wait for the app to appear on your toolbar
- Right click to create a new window
- Add a new project  
- A new project / small project is recommended to use to avoid the slowdown

> GDWisp is a community-built tool, independent of GDevelop and not officially affiliated with it.
