Welcome to the GDWisp Repo!

If you want to **[contribute](docs/contribute)**.

**GDWisp** is tool for GDevelop that aids collaboration through a visual git interface and project management. Check out more about GDWisp at [our website](https://www.gdwisp.com) (with screenshots).

**Current Features**
- **Projects:** Properties, Global Variables
- **Scenes:** Layers, Objects, Groups, Instances, Events, Properties
-  **Objects:** Behavior, Effects
- **Events:** Comments, Standard Events
- **Variables:** Array, String, Number, Boolean
- **Resources**
- **Basic Project List**
Check out our roadmap, philosophy and goals at [Roadmap - GDWisp](https://www.gdwisp.com/roadmap)

**Current Flaws**
- Missing some of features (pre-alpha)
- Some features are slow on large features (Events Rendering)
You can help use fix some flaws/bugs at [[contribute]]

## How to Use
- Download the latest from Releases
- Extract the zip
- Run gdwisp.exe
- Wait for the app to appear on your toolbar
- Right click to create a new window
- Add a new project  
- A new project / small project is recommended to use to avoid the slowdowm

> GDWisp is a community-built tool, independent of GDevelop and not officially affiliated with it.
